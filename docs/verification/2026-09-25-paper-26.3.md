The new fixture's world was restored from the untouched baseline before retrying. CMI, CMILib, and Vault remain disabled only in the new local fixture; their data and the shared server's plugins/configuration were not altered to work around this issue. Full-stack compatibility needs a separate upstream investigation.

The next startup and shutdown succeeded, but its harness still expected the old shutdown marker. After updating that assertion, the complete maintained check passed again. These attempts consumed no extra release/build numbers.

Remaining non-fatal notices: JOML's deprecated Unsafe call in the isolated run, OSHI not recognizing macOS 27, BlueMap's manual-save warning, and LuckPerms/Commodore's Java 27 reflective final-field mutation warning in the maintained fixture. No permissive JVM workaround was added for the LuckPerms notice.

Manual checks still needed: connected-player joins, Java/Bedrock marker toggles and actual map visibility, forced permission enforcement, timer expiry, reconnects/world changes, and interactions with the complete shared plugin stack. Folia behavior was not tested. External messaging integrations were inactive throughout local smoke testing.
